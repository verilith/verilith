# libxml2 2.15.4's runtest suites against verilith-xml's libxml2 ABI: the
# tests that fail, as scripts/test-libxml2.sh lists them (suite, a tab, the
# test), by reason. CI fails if another test fails or a listed one passes.

# The push parser reads a document in UTF-8 as it comes; one in another
# encoding (ISO-8859-1, US-ASCII, UTF-16) it reads whole when the last chunk
# comes, so no SAX call comes before then. These tests push a byte at a time
# and count the calls each byte gives.
