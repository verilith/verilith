# libxml2 2.15.4's runtest suites against verilith-xml's libxml2 ABI: the
# tests that fail, as scripts/test-libxml2.sh lists them (suite, a tab, the
# test), by reason. CI fails if another test fails or a listed one passes.

# Parameter entity references in the internal subset are not expanded (as
# the verified parser does not read them), so the declarations they hold are
# missing (ent7: an element type; xml2: a general entity).
